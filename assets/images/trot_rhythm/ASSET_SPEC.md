# [E4] 트로트 리듬 게임 — 스프라이트 에셋 규격 (관절 리그, 팔꿈치 1자유도)

렌더 방식: 팔은 **부위 분리 관절 리그**. 코드가 각 부위를 축 기준으로 회전·조립.
상완은 고정각, 전완·응원봉만 팔꿈치 각도로 회전. 어깨 관절은 이번 범위 제외(고정).

**시점(중요): 정측면 프로필이 아니라 ¾ 비스듬한 뷰(반측면, three-quarter).**
모든 인물(가수·응원단장·플레이어·관객)은 몸을 관객/화면 쪽으로 살짝 튼 비스듬한 자세로 그린다.
단, 팔(상완·전완·응원봉)의 굴곡/신전은 여전히 **화면 평면 안에서 회전**하므로 리그 부위는 아래 피벗 규칙 그대로 제작(코드 회전 로직 불변). 몸통 스프라이트만 ¾ 각도로 그리면 됨.

모든 파일: `assets/images/trot_rhythm/` 에 **소문자_언더스코어** 네이밍 PNG로 저장.
에셋이 없으면 코드는 기존 절차적 도형 렌더로 **자동 fallback** (앱 안 깨짐).

## 2. 팔 리그 스프라이트 (⚠️ 어깨 1자유도 · 인물별 개별 팔)

**동작: 어깨 굴곡/신전 = 팔 전체가 어깨를 축으로 위/아래로 스윙**(팔꿈치는 지금 고정, 곧게 폄. 2자유도는 추후).
따라서 상완+전완은 함께 회전하지만, 나중 팔꿈치 대비 2부위로 분리 제작.

피벗(회전축) 규칙: **모든 리그 부위는 캔버스에서 "아래로 곧게 뻗은" 자세로 그리고, 회전축을 캔버스 상단-중앙에 둔다.** 코드가 이 상단-중앙 점을 관절에 놓고 회전.

**공유 아님 — 응원단장/플레이어 각각 다른 소매색 팔:**

| 파일명 | 캔버스 | 피벗 | 팁 | 내용 |
|---|---|---|---|---|
| `leader_arm_upper.png` | 96×220 | 상단중앙 = **어깨** | 하단 = 팔꿈치 | 응원단장 상완. **빨강 군악대 소매+금장**. |
| `leader_arm_fore.png` | 96×260 | 상단중앙 = **팔꿈치** | 하단 = 손목 | 응원단장 전완 + **흰 장갑 손**. 빨강 소매 커프. |
| `player_arm_upper.png` | 96×220 | 상단중앙 = **어깨** | 하단 = 팔꿈치 | 플레이어 상완. **흰 소매+금장**(파랑 포인트 가능). |
| `player_arm_fore.png` | 96×260 | 상단중앙 = **팔꿈치** | 하단 = 손목 | 플레이어 전완 + **흰 장갑 손**. 흰 소매 커프. |
| `cheer_stick.png` | 64×300 | 상단중앙 = **손목(그립)** | 하단 = 발광 팁 | 하늘색 LED 응원봉(응원단장·플레이어·관객 공유). |

규칙:
- 각 부위는 **세로로 곧게(12시→6시)** 그린다. 회전은 코드 담당.
- 피벗 끝(상단중앙)을 캔버스 **가로 정중앙·세로 최상단**에 맞춘다.
- 길이 비율(코드 기준): 상완 ≈ 화면높이×0.07, 전완 ≈ ×0.09, 응원봉 ≈ ×0.10.
- 몸통(§1)은 **봉 든 쪽 팔 없이** 제작 → 이 리그 팔이 그 어깨에 붙어 스윙. 반대쪽(허리에 얹은) 팔은 몸통에 그려도 됨.
- ghost(예고)는 코드가 반투명 처리하므로 별도 제작 불필요.

## 4. 제출 방법

- 배경 제거는 **투명 PNG로 바로 내보내기** 권장(초록/검정 크로마키 불필요). remove.bg 대신 포토샵/피그마 투명 배경 export.
- 완성 후 이 폴더에 파일명 그대로 저장 → 코드가 자동 로드, 없는 것은 절차적 렌더로 대체.
- 우선순위: `bg_trot_stage` → `singer_avatar` → 몸통 2종(`body_leader`/`body_player`) → 팔 리그 인물별 4종 + `cheer_stick` → `audience_member` → 가수 표정 2종 → 판정텍스트.
- **오버레이 정합성 규칙**: 가수 입/눈 오버레이는 반드시 `singer_avatar.png`와 **똑같은 512×512 캔버스**에서 해당 부위만 그리고 나머지는 투명하게. 코드가 같은 dst에 겹쳐 그리므로 위치가 자동으로 맞음.
