## 2. 게임 메카닉 확정 사항

### 2.1 저항 방향 구분

팔이 어느 위치에 있든 두 방향 저항 모두 가능:

| 화살 종류 | 아이콘 | 의미 | 모터 동작 |
|----------|--------|------|---------|
| 굽힘저항 화살 | **↓** (굵은 표시) | 아래로 누르는 힘에 버텨라 | 굽힘 방향 저항 제공 |
| 폄저항 화살 | **↑** (굵은 표시) | 위로 올리는 힘에 버텨라 | 폄 방향 저항 제공 |

- 색 구분 없이 방향 아이콘만으로 구별 → 색약 환자도 인식 가능
- 화살 위에 굵은 ↓ 또는 ↑ 아이콘 표시

### 2.2 난이도 파라미터

| Brunnstrom Stage | 방패 크기 | 화살 크기 | 화살 속도 | 유지 시간 |
|-----------------|---------|---------|---------|---------|
| 2 (초기) | 매우 큼 (×1.5) | 큼 (×1.4) | 70 px/s | 0.8초 |
| 3 | 큼 (×1.25) | 보통 (×1.15) | 100 px/s | 1.2초 |
| 4 (기본) | 보통 (×1.0) | 보통 (×1.0) | 140 px/s | 1.8초 |
| 5 | 작음 (×0.82) | 작음 (×0.85) | 190 px/s | 2.4초 |
| 6 (말기) | 매우 작음 (×0.65) | 작음 (×0.70) | 250 px/s | 3.0초 |

### 2.3 다이나믹 모드

- 인지 레벨 3에서 활성화
- 화살마다 크기(0.6~1.5×), 속도(0.7~1.3×) 랜덤 변화
- 에너지 수치도 랜덤 → 고에너지 화살은 더 많은 피해

### 2.4 데미지 시스템

| 이벤트 | 결과 |
|--------|------|
| 화살 막기 성공 | +10점 + 에너지 보너스 (최대 +20) |
| 고에너지 화살 실패 | 방패/성 -2 단계 |
| 일반 화살 실패 | 방패/성 -1 단계 |
| 방패 5단계 도달 | 게임 오버 |

## 3. 그래픽 요소 확정 사항

### 3.1 스타일
- 방패/화살: **3D 모델 → Blender 렌더링 → 2D PNG 스프라이트**
- 배경 성: **실제 중세 성 스타일** (사실적, 황혼 조명)
- 전체 톤: 어둡고 드라마틱

### 3.2 방패 손상 단계 (6장)

| 파일명 | 상태 | Blender 작업 |
|--------|------|-------------|
| `shield_0.png` | 완전한 방패 | 기본 렌더 |
| `shield_1.png` | 흠집 1개 | 긁힘 텍스처 추가 |
| `shield_2.png` | 흠집 2개 + 긁힘 | Roughness 높임 |
| `shield_3.png` | 조각 떨어짐 | Geometry 일부 제거 |
| `shield_4.png` | 심하게 파손 | 형태 일그러짐 |
| `shield_5.png` | 거의 파괴 | 뼈대만 남음 |

- 추가: `shield_glow.png` — 목표 위치 맞췄을 때 글로우 오버레이

### 3.3 화살 (2장)

| 파일명 | 아이콘 | 의미 |
|--------|--------|------|
| `arrow_down.png` | ↓ (굵게) | 굽힘저항 |
| `arrow_up.png` | ↑ (굵게) | 폄저항 |

- 화살 색 구분 없음 (아이콘만으로 구별)
- 화살대: 나무색, 화살촉: 금속색, 깃털: 자연색

### 3.4 성 붕괴 단계 (6장)

| 파일명 | 상태 | Blender 작업 |
