## 1. InMotion ARM

### 하드웨어 특징

- **형태:** 엔드이펙터 로봇 (핸들); 수평면 2축 병진 운동
- **대상 관절:** 어깨 굽힘/폄, 어깨 벌림/모음, 팔꿈치 굽힘/폄 (수평면에서 중력 보상)
- **DOF 매핑:** 핸들 XY 위치 → 화면 커서 XY. 중심에서 멀어지는 방향 = 어깨 굽힘 + 팔꿈치 폄 또는 벌림. 작업 공간은 중심 기준 방사 대칭.
- **필요 보조(Assist-as-needed):** 로봇이 움직임 의도를 감지해 부분 보조; 환자 회복에 따라 보조량 감소.

### 게임 1: 시계 과제 (Clock Task / Adaptive Clock Game)

| 항목 | 내용 |
|------|------|
| **비주얼 테마** | 추상/미니멀 — 어두운 배경에 컬러 원형 |
| **시각 디자인** | 노란 원 = 환자 커서. 빨간 점멸 원 = 목표. 중심 1개 + 시계 방향으로 8개 목표(N, NE, E, SE, S, SW, W, NW), 각 14cm 간격 배치. |
| **메커니즘** | 중심 → 목표 → 중심 순으로 이동. 1라운드 = 16회 이동(왕복 8회). 세션당 20라운드 = 시간당 320회. |
| **관절 매핑** | N = 어깨 굽힘; S = 폄; E/W = 벌림/모음. 대각선 = 복합 운동. |
| **인지 부하** | 낮음 — 순수 운동. 목표 점멸에 주의 집중 필요. |
| **난이도 파라미터** | 목표 크기, 보조 수준(포스 필드), 속도 기준, 작업 공간 반지름. 로봇이 속도·경로 편차에 따라 실시간 보조 조절. |
| **치료 프로토콜** | 표준: 주 3회 × 6주 = 18세션 × 1시간. 세션당 600–1,000회. |

### InMotion ARM 게임 설계 철학

- 모든 과제에서 **커서 = 손** 직접 매핑. 환자는 자신의 손 위치를 원으로 직접 확인.
- 난이도 제어 4요소: 목표 크기, 작업 공간 크기, 최소 이동 속도 기준, 로봇 보조량.
- 매 세션 운동학 데이터(위치, 속도, 힘)를 임상 분석용으로 기록.
- 최신 BIONIK 세대: 경쟁형/협동형 멀티플레이어 변형(환자 vs. 컴퓨터, 환자 vs. 환자, 협동) 추가.

## 2. Armeo (Hocoma)

### 하드웨어 특징

- **제품군:** ArmeoSpring (수동 중력 보상), ArmeoPower (능동 구동), ArmeoBoom (중증 초기 재활), ArmeoSenso (외래/가정용 센서)
- **형태:** 팔 외골격 (어깨 → 손)
- **DOF:** ArmeoSpring = 5 DOF (어깨 3, 팔꿈치 1, 전완 1); 손목 포함 시 6 DOF
  - 어깨 벌림/모음: −169° ~ +50°
  - 어깨 굽힘/폄: +40° ~ +120°
  - 어깨 내/외회전: 0° ~ 90°
  - 팔꿈치 굽힘/폄: 0° ~ 100°
  - 전완 엎침/뒤침: −60° ~ +60°
  - 손목 굽힘/폄: −60° ~ +60°
- **DOF 매핑:** 3D 팔 운동 → 3D 가상 작업 공간의 커서/아바타 이동. 팔을 위·외측으로 들면 커서 상·외측 이동. 손잡이 그립 센서가 게임 내 집기/놓기 이벤트 제어.
- **공통 난이도 파라미터:** 목표 크기, 배경 복잡도, 물체 속도, 방해물 수, 요구 ROM, 중력 보상 수준, 그립력 임계값.

### Armeo 설계 원칙

- 모든 운동: **확장된 수행 피드백** — 화면에 과제 목표 + 환자 수행 동시 표시.
- **1D 운동:** 단일 관절 분리 (중증 환자용).
- **2D 운동:** 수평/수직 평면 이동.
- **3D 운동:** 전체 3D 작업 공간 (중등도 환자용).
- 인지 장애 환자용: **간소화된 시각 필드** 옵션(방해 요소 최소화).
- ArmeoPower(능동 구동): 수동 이동 모드, 능동 보조 모드, 저항 훈련 모드 추가.

## 3. Tyromotion tyroS

### 하드웨어 특징

- **tyroS** = 모든 Tyromotion 기기 공통 소프트웨어 플랫폼. 운동·감각·인지 훈련 + 게임화 + 바이오피드백.
- **Pablo:** 다기능 센서 기기. 손→어깨. 그립, 손목 굽힘/폄, 전완 엎침/뒤침, 어깨 운동 측정.
- **Diego:** 양팔 어깨 외골격/중력 보조. 어깨→손, 양측 훈련.
- **Amadeo:** 손가락 재활 로봇. 개별 손가락 운동.

### DOF 매핑

Pablo 센서 측정 항목: 원통 그립, 핀치 그립, 세 손가락 그립, 손목 굽힘/폄, 엎침/뒤침, 어깨 운동.
게임 축은 활성화된 센서 축에 매핑 — 예: 손목 굽힘/폄 → 게임 수직축, 전완 엎침/뒤침 → 좌우축.

## 5. ReoGo (Motorika)

### 하드웨어 특징

- **형태:** 엔드이펙터 로봇 (3D), 완전 전동 로봇팔 + 핸들
- **운동 범위:** 3D 도달 — 전방, 측방, 위. InMotion(2D 수평면)과 달리 **수직 도달 포함**.
- **DOF 매핑:** 어깨 굽힘/폄, 어깨 벌림/모음, 팔꿈치 굽힘/폄 복합 3D 경로.

### 작동 모드 (게임이 아닌 치료 프레임워크)

| 모드 | 설명 |
|------|------|
| **안내(Guided)** | 로봇이 팔을 설정 경로로 완전 제어 (완전 수동) |
| **시작(Initiated)** | 환자가 움직임 시작, 로봇이 이어서 보조 |
| **단계 시작(Step Initiated)** | 환자가 각 구간마다 시작 |
| **추종 보조(Follow Assist)** | 환자 주도, 로봇이 필요에 비례 보조 |
| **자유(Free)** | 환자 자유 이동, 로봇 보조 없음 (능동) |

### 게임 (공개 정보 제한)

Motorika는 상세 게임 카탈로그를 공개하지 않음. 임상 문헌·시설 설명 기반:
- 3D 공간에 배치된 목표로 **도달** (ADL 기능 동작 시뮬레이션: 컵 집기, 선반에 물건 올리기 등)
- **미로/통로 탐색** 과제 — 3D 궤적 제어
- 방향·거리가 다른 **목표 획득** 과제
- 경로는 사전 프로그램 또는 치료사 맞춤 설정

**운동→게임 매핑:** 핸들 3D 위치 → 가상 장면 커서/아바타 위치 직결. 앞 = 화면 안. 위 = 위. 측방 = 좌우.

- **규제:** FDA 510(k) 승인 (미국).
- **원리:** 환자 움직임 → 화면 3D 아바타에 실시간 매핑.
- **핵심 기능 — 거울 치료 모드:** 건측 팔 사용 → 환측 팔 아바타에 반사 표시. 거울 뉴런 시스템 활성화.

### DOF 매핑

카메라가 어깨·팔꿈치·손목·손 전체 운동학 추적. 게임 축을 임의 관절 또는 복합 운동에 매핑 가능.

### 알려진 운동

| 운동 | 테마 | 메커니즘 | 운동 |
|------|------|----------|------|
| 광산 수레 | 광산/액션 | 팔 운동으로 터널 질주 | 도달, 어깨/팔꿈치 폄 |
| 토끼 건너기 | 자연/귀여움 | 타이밍에 맞춰 팔 반복 동작 | 리드미컬한 도달 |
| 꽃 정원 | 자연 | 꽃 따기/물 주기 | 어깨 굽힘, 도달 방향 |
| ADL 시뮬레이션 | 일상 생활 | 가상 물체(컵, 선반, 문) 도달 | 치료사 설정 |

### 설계 철학

- 운동 기반: 과제 특이적 훈련, 반복 운동, 운동 학습 진행.
- 아바타 피드백 → **동작 관찰** 자극: 환측 팔이 움직이는 것을 보면 실제 움직임이 제한적이어도 거울 뉴런계 활성화.
- 난이도: 물체 거리, 이동 속도 요구, 요구 관절각 범위, 시각 복잡도.
- 만성 뇌졸중 환자 90%가 동기 향상 보고; 10세션 내 훈련 강도 2배 증가 (10세션째 17.3회/분).

### 8.2 게임 유형 분류 체계 (문헌 + 상용 시스템 기반)

#### A형: 목표 획득 (점→점 도달)
- **패턴:** 이산 목표 등장 → 도달 → 성공 → 다음 목표
- **운동 유형:** 탄도적 도달 (어깨+팔꿈치로 손을 목표로 이동)
- **사례:** InMotion 시계 과제, KINARM VGR, Neofect 스마트 보드 목표 도달
- **인지 부하:** 낮음(단순)~중간(다중 목표 순서)
- **핵심 난이도 조절:** 목표 크기, 작업 공간 반지름, 목표 제시 속도, 순서 목표 수

#### B형: 연속 궤적 추적
- **패턴:** 이동하는 또는 정해진 경로 안에 커서를 유지 (이산 끝점 없음)
- **운동 유형:** 부드럽고 연속적인 다관절 협응
- **사례:** InMotion 미로, ArmeoSpring 공 굴리기, ReoGo 경로 추적
- **인지 부하:** 중간 (공간 계획, 부드러운 제어)
- **핵심 난이도 조절:** 경로 폭, 경로 복잡도(곡률), 경로 진행 속도

#### C형: 반응적 물체 차단
- **패턴:** 물체가 작업 공간으로 이동 → 반응적으로 차단
- **운동 유형:** 다방향 빠른 탄도적 도달
- **사례:** ArmeoSpring 골키퍼, Neofect 야구, KINARM 물체 치기
- **인지 부하:** 중간 (타이밍, 궤도 예측)
- **핵심 난이도 조절:** 물체 속도, 궤도 분산, 동시 물체 수

#### D형: 선택적 반응 / Go-No-Go
- **패턴:** 여러 물체 유형 등장 → 특정 목표만 치고 나머지 피하기
- **운동 유형:** C형과 동일하나 억제 제어 추가
- **사례:** KINARM OHA, ArmeoSpring 해적 모험 (부분)
- **인지 부하:** 높음 (목표 유형 작업 기억, 반응 억제)
- **핵심 난이도 조절:** 방해물 유형 수, 물체 속도, 목표/방해물 비율

#### E형: 양팔 협응
- **패턴:** 양팔이 협력(대칭 또는 차별적)하여 과제 수행
- **운동 유형:** 양측 어깨+팔꿈치 협응
- **사례:** KINARM 막대 위 공, 양측 VR 차단 과제
- **인지 부하:** 중간~높음 (팔간 협응, 양팔 타이밍)
- **핵심 난이도 조절:** 결합 제약(대칭 vs. 비대칭), 물체 동역학, 목표 위치

#### F형: ADL 시뮬레이션
- **패턴:** 실제 기능 과제 모사 (요리, 낚시, 초밥, 따르기)
- **운동 유형:** 과제별 다양 — 직업 기반 운동 패턴
- **사례:** Neofect 초밥 열차(전완 엎침/뒤침), 낚시(요측/척측 편위), MindMotion ADL
- **인지 부하:** 낮음~중간 (과제 특이적 순서화)
- **핵심 난이도 조절:** 속도, 요구 정확도, 아이템 수, 방해 아이템

#### G형: 리듬/기억 운동 과제
- **패턴:** 운동 시퀀스를 암기하고 시간에 맞춰 재현
- **운동 유형:** 순서적 관절 이동, 타이밍 중요
- **사례:** Neofect 드럼 연주, Amadeo Says
- **인지 부하:** 높음 (작업 기억, 순차 회상, 운동 리듬)
- **핵심 난이도 조절:** 시퀀스 길이, 템포, 패턴 복잡도

#### H형: 인지-운동 이중 과제
- **패턴:** 운동 수행 + 명시적 인지 과제 결합 (기억, 순서 연결, 언어)
- **사례:** KINARM 선 잇기, KINARM 공간 기억, KINARM 쌍 연합 학습
- **인지 부하:** 매우 높음

### 8.3 난이도 파라미터 프레임워크 (전 시스템 공통)

| 파라미터 | 설명 | 난이도에 미치는 영향 |

| **물체 속도** | 이동 게임 물체 속도 | 빠를수록 어려움 |
| **물체 수** | 동시 물체 수 | 많을수록 인지+운동 부하 증가 |
| **방해물 밀도** | 비목표 물체 수 | 많을수록 억제 요구 증가 |
| **궤적 제약** | 경로 추적 채널 폭 | 좁을수록 어려움 |
| **중력 보상** | 로봇 지지 수준 | 지지 감소 = 어려움 |
| **요구 ROM** | 이벤트 유발 최소 ROM | 넓을수록 어려움 |
| **시각 복잡도** | 배경 혼잡도, 애니메이션, 방해 요소 | 많을수록 인지 부하 증가 |
| **보조 수준** | 로봇 힘 보조 | 보조 감소 = 어려움 |
| **보정 오프셋** | 운동→게임 1:N 비율 | N 클수록 덜 민감 = 어려움 |

### 8.4 전 상용 시스템에서 관찰된 원칙

1. **커서 = 손 메타포는 보편적.** 모든 시스템에서 환자의 손/팔 위치가 시각 커서, 아바타, 게임 오브젝트에 직접 매핑. 입력 추상화 없음 — 움직임이 곧 제어.

2. **방사형 목표 배치가 지배적.** 도달 과제 표준 배치: 시계 방향 동일 각도 8개 목표. 모든 이동 방향에 걸쳐 훈련 분산.

3. **ADL 메타포가 참여를 높임.** 낚시, 요리, 야구 등 실생활 활동으로 프레이밍된 과제가 추상 도달 과제보다 환자 동기 높음.

4. **근위 다관절 과제가 신경가소성 이득 최대.** ArmeoSpring 연구: 공 굴리기, Fly High 등 근위 다관절 운동이 원위 분리 과제보다 어깨/팔꿈치 기능 회복 우위.

5. **단순 과제에서 천장 효과 조기 발생.** Balloons(ArmeoSpring) — 초기 점수 빠르게 포화. 쉬운 과제는 장기 훈련 가치 제한. **점진적 난이도 필수**.

6. **적응적 난이도는 필수.** 모든 상용 시스템이 자동 난이도 조절 구현: Neofect는 AI 기반, Armeo/KINARM은 치료사 제어, InMotion은 실시간 힘 조절.

7. **인지 오버레이 효과 있음.** Go/No-Go 및 순서 기억 과제가 참여도를 높이고 전전두피질을 활성화 → 주의 메커니즘을 통한 운동 학습 강화 가능.

8. **양팔 과제는 적지만 높이 평가됨.** KINARM 막대 위 공이 몇 안 되는 진정한 양팔 과제. 양측 훈련은 특히 만성 뇌졸중에서 독특한 신경가소성 이득 보임.
