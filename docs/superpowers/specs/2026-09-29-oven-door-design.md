# [E3] 오븐 문 열기 게임 — 설계

**작성**: 2026-09-29
**관절**: 오른쪽 어깨 바깥돌림 (`rShoulderRo`), 팔꿈치 90°
**대체 대상**: 포션메이커 v2 (`docs/potion_maker_build_guide.md`, 커밋 `7bfbd4e`) — 폐기

---

## 1. 왜 바꿨나

포션메이커는 두 가지 문제가 있었다.

- 큰 통과 작은 병으로 역할을 나눈 규칙이 직관적이지 않았다. 환자가 규칙을 외워야 했다.
- 환자마다 더 많이 쓰게 할 방향(바깥돌림)을 강조하기 어려웠다. 레버는 양방향 조작이라 안쪽돌림도 같은 비중으로 쓰였다.

오븐 문 열기는 두 문제를 동시에 푼다. **문은 바깥돌림으로만 열리고**, 얼마나 열어야 하는지는 **음식 크기로 눈에 보인다.**

## 2. 훈련 목표

| 목표 | 게임 요소 |
|---|---|
| 바깥돌림 가동범위 반복 | 음식 하나에 두 번 연다 (넣을 때, 꺼낼 때) |
| 끝 범위 유지 (등척성) | 음식이 들어가고 나오는 동안 문을 계속 열고 있어야 한다 |
| 근력 | 모터가 문에 저항을 건다. 치료사가 0~3kg에서 고른다 |
| 공동운동 분리 | 팔꿈치 90° 고정 상태에서 어깨 회전만 수행 |

편마비 어깨는 안쪽돌림근 경직으로 바깥돌림이 제한되는 경우가 많다. 이 게임은 그 방향만 반복한다.

## 3. 입력과 로봇

- **관절**: `rShoulderRo`. 현재 하드웨어는 오른팔만 지원한다 (`lib/robot_protocol.dart`의 `currentlySupportedParts` = `rShoulderEF`, `rShoulderRo`, `rElbow`). `rShoulderRo`는 부호 반전 대상이 아니다.
- **각도 입력**: `GameMotorController.angleStream` (관절별 텔레메트리 → UI 각도).
- **문 열림**:

```
p = config.normalizer.normalize(raw)   // 0 = 안쪽 끝, 1 = 바깥 끝
문 열림 = clamp(p / config.romRatio, 0, 1)
```

`romRatio`는 Brunnstrom 단계별 값(2단계 0.4 … 5단계 1.0)이다. **회복 단계가 낮으면 가동범위의 40%만 돌려도 문이 활짝 열린다.**

- **저항**: `GameMotorController.startIsotonic(저항kg, targetAngle)`. 상한은 컨트롤러의 `maxResistance`(5.0)이 막는다. `GameConfig.canUseResistance`가 false인 2~3단계는 저항 선택을 막고 0으로 고정한다.
- **팔꿈치 90°**: 로봇이 잡아 주는 것이 목표다. 현재 프로토콜은 한 번에 관절 하나만 다루므로 펌웨어 기능이 필요하다(포션메이커 가이드 부록 A와 같은 요청). 준비 전에는 화면에 안내를 띄우고 치료사가 잡아 준다.

## 4. 게임 루프

```
음식 하나 =
  ① 넣기   문을 요구 열림까지 열고 유지 → 트레이가 들어감 → 문 닫기
  ② 굽기   팔을 내리고 쉰다 (8초, 온도계와 타이머 표시)
  ③ 벨     다 구워지면 벨이 울린다
  ④ 꺼내기 다시 문을 열고 유지 → 음식이 나옴 → 완성 음식이 선반에 놓인다
```

목표 개수만큼 구우면 끝난다. 최대 시간은 8분이다.

## 5. 규칙

### 5-1. 열고 유지하기

- 문 열림이 **요구 열림 이상**이면 진행 막대가 찬다. 막대가 다 차면(유지 시간 경과) 음식이 들어가거나 나온다.
- **유지 중 요구 열림 밑으로 내려가면 음식이 떨어진다.** 그 음식은 실패로 끝나고 다음 음식으로 넘어간다.
- 손떨림으로 실패하지 않도록 **0.3초의 유예**를 둔다. 0.3초 안에 다시 요구 열림을 넘기면 막대가 이어진다.
- 한 번 여는 동작 = 반복 1회. 음식 하나에 최소 2회다.

### 5-2. 벨과 타는 것

- 굽기가 끝나면 벨이 울린다. **여유 시간 안에 꺼내기를 끝내야 한다.** 여유 시간은 난이도별로 다르다(6-1 표).
- 여유 시간이 지나면 음식이 탄다. 탄 음식은 선반에 놓이지 않고 점수도 없다.
- 남은 시간은 온도계 색과 숫자로 보여 준다.

### 5-3. 결과

| 결과 | 조건 | 연출 |
|---|---|---|
| ✅ 완성 | 넣기와 꺼내기를 모두 성공 | 김이 나는 음식이 선반에 놓인다 |
| 💥 떨어뜨림 | 유지 중 문이 닫힘 | 음식이 바닥에 떨어져 굴러간다 |
| 🔥 탄 음식 | 벨 후 10초 초과 | 까맣게 탄 음식과 연기 한 줄기 |

실패해도 목숨은 없다. 떨어뜨린 음식과 탄 음식도 **목표 개수에는 포함**한다. 운동량이 목표이므로 판이 끝없이 길어지지 않게 한다. 점수와 선반 전시는 완성한 음식에만 준다.

## 6. 난이도

### 6-1. 레벨 (음식 크기)

| 레벨 | 음식 | 요구 열림 | 유지 시간 | 꺼내기 여유 시간 | 목표 개수 | 최소 반복 |
|---|---|---|---|---|---|---|
| 1 | 쿠키 | 35% | 1.0초 | 16초 | 4개 | 8회 |
| 2 | 머핀 | 45% | 1.5초 | 14초 | 5개 | 10회 |
| 3 | 식빵 | 55% | 2.0초 | 12초 | 6개 | 12회 |
| 4 | 피자 | 70% | 2.5초 | 10초 | 7개 | 14회 |
| 5 | 케이크 | 85% | 3.0초 | 8초 | 8개 | 16회 |

음식이 커지면 문을 더 열어야 하고 더 오래 버텨야 한다. 크기 하나로 두 가지가 같이 커진다.

**꺼내기 여유 시간**은 벨이 울린 뒤 음식이 타기까지의 시간이다. 난이도가 올라갈수록 짧아진다. 여유 시간 안에는 유지 시간도 들어가야 하므로, 레벨 5는 8초 안에 문을 열고 3초를 버텨야 한다. 여유 시간이 유지 시간의 최소 2.5배가 되도록 유지한다.

### 6-2. 실제 회전 각도 (캘리브레이션 가동범위 60° 기준)

| | 레벨 1 (쿠키) | 레벨 5 (케이크) |
|---|---|---|
| Brunnstrom 2단계 (romRatio 0.4) | 약 8° | 약 20° |
| Brunnstrom 5단계 (romRatio 1.0) | 21° | 51° |

### 6-3. 저항 (치료사가 선택)

| 저항 | 대상 |
|---|---|
| 0kg | Brunnstrom 2~3단계는 항상 여기. 가동범위와 유지 시간만 훈련 |
| 1~3kg | 4단계 이상. 회차마다 올려 가며 근력 훈련 |

게임 설정 화면에 저항 선택을 추가한다. 4단계 미만이면 선택이 비활성화된다.

### 6-4. 인지 레벨

`CognitiveLevel` 기존 값을 그대로 쓴다(오브젝트 크기, 파티클 수, HUD 표시 범위).

## 7. 점수와 기록

| 이벤트 | 점수 |
|---|---|
| 넣기 성공 | +50 |
| 꺼내기 성공 (= 음식 완성) | +100 + 신속 보너스 `round(50 × 남은 여유 시간 / 전체 여유 시간)` |
| 떨어뜨림 / 탄 음식 | 0 |

- `GameResult.hits` = 성공한 유지 동작 수, `misses` = 떨어뜨림 + 탄 음식
- `accuracy` = hits / (hits + misses)
- `angleHistory`의 `event` 값: `door_open`, `door_close`, `insert_done`, `drop`, `bell`, `take_done`, `burnt`

## 8. 화면

- **오븐 정면도.** 문은 **왼쪽에 경첩이 있고 오른쪽으로 열린다.** 오른팔 바깥돌림은 손이 바깥(화면 오른쪽)으로 움직이므로 방향이 일치한다.
- 문 열린 정도를 위에서 본 작은 평면도로 함께 보여 준다. 요구 열림 위치에 표시를 둔다.
- 유지 진행 막대는 문 옆에 세로로 둔다.
- 오븐 안: 굽는 중인 음식, 온도계, 타이머.
- 선반: 완성한 음식들.
- 안내 문구: "문을 활짝 열어 주세요", "그대로 잡고 계세요", "다 됐어요! 꺼내세요".
- 분위기는 트로트·포션메이커와 같은 밝은 동화풍(크림색 배경 `#FFF7E6`, 진갈색 외곽선 `#3B2A1A`). 1차는 Canvas 도형, 스프라이트는 나중에.

## 10. 임상 확인이 필요한 항목

1. 바깥돌림만 반복하는 구성이 적절한가. 안쪽돌림은 복귀 동작으로만 쓰인다.
2. 저항 범위(0~3kg)와 4단계 이상 제한이 맞는가.
3. 난이도별 유지 시간(1~3초)과 반복 횟수(8~16회), 최대 8분이 한 세션으로 적절한가.
4. 유지 중 문이 닫히면 음식이 떨어지는 실패 연출이 고령 환자에게 과하지 않은가.
5. 로봇이 팔꿈치를 90°로 옮길 때의 속도와, 비상정지·연결 끊김 시 고정 해제 여부.

## 11. 범위 밖

- 왼팔 지원 (하드웨어 미지원)
- 굽는 도중 자유롭게 열어 확인하기 — 넣기와 꺼내기 두 번으로 고정했다
- 스프라이트, BGM, 효과음 — 코어 완성 후
